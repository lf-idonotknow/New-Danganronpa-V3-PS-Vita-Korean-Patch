# 뉴 단간론파 V3 한국어 패치

《뉴 단간론파 V3 모두의 살인 신학기》 PS Vita 일본판의 비공식 한국어 패치입니다.

**현재 배포 준비 중입니다.** 설치 파일과 설치·제거 방법은 첫 릴리스에 함께 제공할 예정입니다.

## 한글화 내용

- 본편 대사와 학급재판 대사
- 메뉴, 전자수첩, 게임 안내
- 재판 미니게임 문구와 게임 화면에 표시되는 이미지 일부

## 설치하기 전에

| 항목 | 기준 |
| --- | --- |
| 기종 | PS Vita |
| 원본 | 일본판 `PCSG00936` |
| 공식 업데이트 | `1.03` 설치 필요 |

공식 업데이트 `1.03`이 적용된 일본판을 준비해 주세요. 비타에서는 한글 패치를 `rePatch` 폴더에 적용합니다. Vita3K 설치 방법과 지원 환경은 배포판 검증 후 릴리스에서 안내하겠습니다.
